Custom Commands

Define your own !trigger → reply pairs. When anyone types the trigger in chat, the bot answers with your text. Perfect for FAQs, rules summaries, or recurring jokes.

Incoming Webhooks

Generate a secret URL you can POST to from any external service. Whatever payload you send becomes a Discord announcement in the channel you pick. Useful for Zapier, GitHub, custom scripts, etc.

Each webhook has a unique secret in its URL — keep it private.

External API Hooks (outgoing)

Push events out of Discord — when the bot does something, it POSTs a JSON payload to your URL. Useful for analytics, mirroring to another platform, or building automations.

Currently supported events: announcement_posted. More coming soon.
