Built-in modules

Everything a server admin actually needs.

Twelve modules, one bot. Toggle each one from the web dashboard — no config files, no restarts.

Scheduled Announcements

Plan announcements days in advance with /schedule or the dashboard. Posted on time as styled embeds — even if your moderators are asleep.

Giveaways

Start a timed giveaway with /giveaway. Members react 🎉 to enter — winners are picked automatically and announced when time's up.

Starboard New

The classic Carl-bot starboard. React with ⭐ — once your threshold is hit, the message gets reposted to your starboard channel with author and jump link.

Embed Builder New

Post rich embeds straight from Discord with /embed. Supports color names, images, thumbnails, author lines, footers and clickable titles — no dashboard trip needed.

Invite Tracking

See exactly who invited whom. Live leaderboards in the dashboard, plus /invites for instant lookups in chat.

Polls & Reminders

Quick reaction polls with /poll and personal reminders with /remind. Persisted to disk — they survive restarts.

Sticky Messages

Pin a message to the bottom of any channel — every time someone posts, the bot re-stickies it so important info stays visible.

Welcome Flow & Auto-Roles

Automatic welcome messages and a join-role for every new member. Configure the welcome channel and role from the dashboard in one click.

Live Server Analytics

Messages per day, top chatters, voice-minute tracking, online ratio, channel/role/boost counts — straight from /stats or the dashboard.

One-Click Setup Templates

Spin up a community / gaming / study server in seconds with /setup_template. Pre-built channel categories, roles and welcome flow.

Custom Commands & Webhooks

Define !triggers in the dashboard, accept incoming HTTP webhooks, and forward server events out to your own services with outgoing hooks.

Beautiful Web Dashboard

Manage every announcement, giveaway, sticky, hook and template from a Byte Labs dashboard — Discord OAuth login, no command syntax to memorise.

Slash Commands

Every command at a glance.

Type / in Discord to bring up the full list — autocomplete, descriptions, the works.

/announce

Post a styled embed announcement to any channel right now.

/schedule

Schedule an announcement for later — durations like 30m, 2h, 1d.

/list_schedules

See every pending scheduled announcement with its ID.

/cancel_schedule

Cancel a pending announcement by its ID.

/broadcast

Push the same message to multiple channels at once.

/giveaway

Start a timed giveaway — members react 🎉 to enter.

/list_giveaways

List all active giveaways in the server.

/end_giveaway

End an active giveaway early and pick winners now.

/poll

Quick reaction poll with up to 4 options.

/remind

Set a personal reminder — survives restarts.

/sticky

Stick a message to the bottom of a channel.

/embed

Build & post a rich embed without the dashboard.

/setup-starboard

Configure ⭐ starboard channel + threshold.

/starboard-stats

See starboard config and total starred count.

/invites

Invite leaderboard or per-user lookup.

/stats

Members, online, channels, roles, boosts, owner.

/setup_template

One-click community / gaming / study server.

/set_welcome_role

Auto-assign a role to every new member.

/set_log_channel

Pick where join/leave logs are written.

/help

Show the full command list right inside Discord.
