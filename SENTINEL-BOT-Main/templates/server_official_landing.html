Built-in modules

Everything a server admin needs.

Each module is toggleable from the web dashboard, and every command works with Discord's native slash UI.

Scheduled Announcements

Plan announcements days in advance — from the dashboard or with /schedule. Posted automatically with styled embeds.

Giveaways

Start a timed giveaway with /giveaway. Members react 🎉 to enter — winners are picked automatically when time's up.

Invite Counter

See exactly who invited whom. Live leaderboards in the dashboard plus /invites for quick lookups in chat.

Server Statistics

Member counts, online presence, bot ratio, channels, roles, boosts — pulled live with /stats or shown on the dashboard.

Permission-Aware

Every management command requires the Manage Server permission, so only your trusted staff can post or run giveaways.

Slash Commands

All commands at a glance.

Type / in Discord to bring up the full list.

/announce

Post a styled embed announcement to any channel right now.

/schedule

Schedule an announcement for later — accepts durations like 30m, 2h, 1d.

/list_schedules

See every pending scheduled announcement with its ID.

/cancel_schedule

Cancel a pending announcement by its ID.

/giveaway

Start a timed giveaway. Members react 🎉 to enter; winners chosen automatically.

/list_giveaways

List all active giveaways in the server.

/end_giveaway

End an active giveaway early and pick winners now.

/invites

Show the invite leaderboard, or look up a specific user's invite count.

/stats

Detailed server stats: members, online, channels, roles, boosts, owner.

/serverinfo

Quick at-a-glance server snapshot.

/help

Show the full command list right inside Discord.
