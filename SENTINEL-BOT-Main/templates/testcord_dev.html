Prefix commands t!

🏓
t!ping
Check if Testcord is alive and show latency.
📢
t!echo [text]
Echo a message back as an embed.
👤
t!userinfo [@user]
Show account info for a member.
🏠
t!serverinfo
Show details about the current server.
🖼️
t!avatar [@user]
Display a user's full avatar.
🎖️
t!roles [@user]
List all roles assigned to a member.
⚠️
t!warn @user [reason]
Simulate a warning — nothing is saved to DB.
⏱️
t!timeout @user [dur] [reason]
Simulate a timeout — member is not affected.
🖋️
t!embed [#color] [text]
Preview a custom embed layout.
❓
t!help
Show the full Testcord command list.

Slash commands /tc-*

🏓
/tc-ping
Check Testcord latency via slash command.
👤
/tc-userinfo @user
Show information about a user.
⚠️
/tc-warn @user [reason]
Simulate issuing a warning — test only, nothing is saved.
🔨
/tc-ban @user [reason]
Simulate a ban — member is NOT actually banned.
👢
/tc-kick @user [reason]
Simulate a kick — member is NOT actually kicked.
⏱️
/tc-timeout @user [duration]
Simulate a timeout — NOT applied to the member.
🖋️
/tc-embed [title] [desc] [color]
Test the embed builder and preview output.
📋
/tc-logs #channel
Send a sample log embed to test a log channel.
🔐
/tc-captcha
Preview the captcha setup command response.
🤖
/tc-automod
Preview automod status for this server.
