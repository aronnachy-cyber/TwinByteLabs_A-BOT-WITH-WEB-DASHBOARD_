Setup guide

Testcord token is not configured
  1. Create a new Discord application at discord.com/developers and add a bot user.
  2. Copy the bot token and add it as a secret named TESTCORD_TOKEN in your Replit environment secrets.
  3. Optionally add TEST_GUILD_ID (your test server's ID) for instant slash command sync instead of the usual 1-hour global delay.
  4. Run python SENTINEL-BOT-Main/testcord.py to start the bot (separate process from the dashboard).
