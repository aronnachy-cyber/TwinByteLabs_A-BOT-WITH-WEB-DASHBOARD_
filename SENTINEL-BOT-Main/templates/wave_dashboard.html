Slash Commands

These commands are available to server administrators in any guild the Wave bot has joined.

/here
Sets the current channel as the Wave announcement channel for this server. Run this once before using /start.
/start title: … url: …
Creates a watch room and posts the viewer link in the configured channel. Sends the private host link to the admin via ephemeral reply.
