What's included

Watch parties, fully engineered.

Every piece of the streaming stack is built-in — from ingestion to sync to chat overlay.

Any Stream URL

YouTube live, Twitch, direct HLS .m3u8, RTMP, or any direct video URL. Wave📶 handles extraction and conversion automatically via yt-dlp + FFmpeg.

FFmpeg HLS Pipeline

Your server pulls the raw stream and transcodes it into HLS segments. Works with any source — no relying on third-party embeds that block or expire.

Real-Time Sync

Host plays, pauses, or seeks — all viewers snap to the same position instantly. Uses WebSocket-driven state propagation for sub-second sync latency.

Watch Party Rooms

Each Discord server gets its own room with a shareable link. Invite anyone — members join via browser, no install needed.

Live Chat Overlay

Floating chat panel over the player so your community reacts in real time without leaving the stream page. Messages sync across all viewers.

Discord as Controller

/watch, /sync, /status, /endstream — control the whole stream from Discord. The bot links your community to the room instantly.

Host Permissions Soon

Only the room creator has play/pause/seek control. Viewers are locked to the host's stream position — perfect for movie nights.

Viewer Count & Presence Soon

See who's in the room, who joined late, and who's still buffering. Full presence list with Discord avatars pulled automatically.

Scheduled Streams Soon

Schedule a watch party for a future time. Wave📶 posts a reminder in Discord and opens the room automatically at the right moment.

Discord Commands

Control everything from Discord.

Wave📶 keeps Discord as your hub. The web room is where people watch — Discord is where you control it.

/watch [title] [url]

Create a watch-party room. Optionally set a title and pre-load a stream URL. Posts the shareable room link.

/sync

Force all viewers to snap to the host's current playback position. Fixes drift in large rooms instantly.

/status

Check the current room — playing/paused, stream URL, position timestamp, and viewer count.

/endstream

Close the room, disconnect all viewers, and clean up. Requires Manage Server permission.

/wave-help

Full command reference with how-it-works guide and platform link.
