Features

Everything you need to stream together

Built-in Mini Browser
Browse to any URL — sports streams, video sites, anything — and preview it right inside the Wave room before going live.
Video Auto-Detection
Can't find the stream link? Hit "Find Videos" and Wave scans the page for HLS, MP4, and live stream URLs automatically.
Shared Viewing Room
Everyone in the room sees exactly what the host is streaming. Switch streams on the fly — all viewers update instantly.
Live Chat
Built-in chat sidebar so viewers can react and talk while watching — no external app needed.
Discord Bot Control
Launch a stream session right from Discord. Admins run /start and the join link is posted to the server automatically.
Admin-Only Controls
Only server admins can start streams and control playback. Viewers can watch and chat — no chaos.
How It Works

Up and running in three steps

1
Set your stream channel
In Discord, go to the channel where you want stream announcements posted and run the slash command. Wave will remember it.
/here
2
Start a session
Run /start with an optional title and URL. Wave creates a watch room and posts the join link in your channel. You get a private host link.
/start title:Match Day url:https://cricstreams.tv/
3
Stream & watch together
As host, browse to any page in the mini browser. Find videos with one click, then hit "Stream This" — all viewers see it instantly. Chat together in real time.
